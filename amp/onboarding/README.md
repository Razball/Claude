# Onboarding Playbook

The Sprint engagement: first 2–4 weeks with a new AMP client. Goal is 80% of Client Module Layers 0–2 populated within 90 minutes of first session.

## Structure

```
onboarding/
├── README.md                  # this file
├── sprint-playbook.md         # the conversation script (session by session)
├── discovery-questions.md     # ordered question bank
├── dependency-tracker.md      # what must be collected by when
├── week-by-week.md            # 4-week Sprint outline
└── deliverables.md            # what the client gets
```

## Rule
The playbook is extracted from real client runs, not designed in the abstract. v0.1 is a scaffold. The first real version is written *after* running a second client manually through the Sprint.

## Status
v0.1 — scaffold only. Real content populated after Phase 4 (see B6).
